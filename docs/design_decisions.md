# Design Decisions

## 1. Architectural Clarifications from the Paper & Prompt

### Attention Dimension & Visual Index `j`
- **What `i` represents**: `i` represents the textual token index from the natural language query after tokenization. 
- **What `j` represents**: `j` represents the visual token index. In a standard ViT architecture applied to video, this could be a spatial token within a specific frame, or a frame-level embedding (if spatial tokens are already pooled). Given that we are adapting VCLIP (which often operates at the frame or spatial-temporal token level) and the query is text, we assume `j` represents the token sequence generated by the Vision Encoder. *For this implementation, unless VCLIP dictates otherwise, we assume `j` represents temporal frame-level embeddings or spatio-temporal tokens.*
- **Tensor Dimensions**: Let `N` be batch size, `T` be frames, `L_v` be visual tokens per frame, `L_t` be text tokens. The visual features are `(N, T * L_v, D)` or `(N, T, D)`. Text features are `(N, L_t, D)`.
- **Where `c_i` is applied**: Query-attribute confidence `c_i` is applied as a multiplicative factor to the text token dimension `i` after computing the attention logits.
- **Where `q_j` is applied**: Frame quality `q_j` is applied as a multiplicative factor to the visual token dimension `j`. If `j` represents spatial tokens within a frame, `q_j` for a frame is broadcasted to all spatial tokens in that frame.
- **Final Normalization**: Simple sum-division over the `j` dimension to ensure attention weights sum to 1. `\alpha'_{ij} = \frac{\alpha'_{ij}}{\sum_j \alpha'_{ij}}`.

### VCLIP Baseline Ambiguities & Adaptations (Stage 3)
- **Attribute Inference Mechanism**: The VCLIP paper describes using learned prompts to construct an attribute sentence. Since the full text-reconstruction methodology isn't strictly necessary when producing a continuous embedding vector $f_{att}(x^t)$, our implementation softens this step. We learn $K$ continuous prompts ($K=41$ attributes), compute their cosine similarity to the visual frame, and use a softmax attention to create a weighted combination of the prompts as $f_{att}(x^t)$. This prevents discrete tokenization from breaking backpropagation.
- **Co-Attention Output Fusion**: The VCLIP paper describes a bidirectional co-attention (Text$\rightarrow$Vis and Vis$\rightarrow$Text) using the phrase "and visa versa" but fails to specify how the two resultant tensors are merged before entering the temporal transformer. **Decision**: We chose to concatenate the two outputs along the feature dimension and project them back down to the target embedding dimension ($D=512$) using a linear layer, which is a standard approach in visual-language co-attention architectures.
- **Strict Query Independence**: Our VCLIP-style video branch produces a query-independent gallery embedding, operating blindly from the external witness statement, matching the architectural separation required for efficient Re-ID gallery caching.

### MCTF Parameters
- The MCTF paper uses fixed hyperparameters (`\tau_{info}=1`, `\tau_{sim}=1/20`, `\tau_{size}=1/40`).
- The learnable extension will maintain three parameters per layer, implemented as `nn.Parameter` with appropriate initialization and constraints (e.g., positivity via Softplus or similar) when Stage 9 is reached.

## 3. Evaluation & Experimental Roadmap

Based on the nature of our Reliability-Aware formula ($\alpha'_{ij} = \frac{\alpha_{ij} c_i q_j}{\sum \alpha_{ij} c_i q_j}$), the mechanism acts as an **inference-time reliability-aware matching mechanism without requiring additional training**. It biases the matching toward higher-quality frames and penalizes unreliable text attributes without strictly requiring the underlying embeddings to be retrained.

To scientifically isolate the value of this mechanism, we define the following rigorous 4-way ablation progression:

- **Baseline**: Matching with no reliability ($\alpha_{ij}$).
- **+ $q_j$**: Matching with only visual reliability ($\alpha_{ij}q_j$).
- **+ $c_i$**: Matching with only text reliability ($\alpha_{ij}c_i$).
- **+ $c_iq_j$**: Matching with dual cross-modal reliability.

These will be tested across 3 distinct degradation axes using **TVPReid** as our primary dataset:
1. **Query Incompleteness**: (Full/Partial/Short) based on semantic parsing of TVPReid captions offline. Measures retrieval under missing information (where remaining $c_i = 1$).
2. **Visual Degradation**: (Clean/Mild Blur/Strong Blur).
3. **Text Uncertainty**: A small targeted ablation where uncertainty phrases (e.g. "maybe") are injected to evaluate $c_i$ suppression.

*Note: A secondary phase (Model 2) will involve explicit retraining on dynamically augmented degraded data to observe if accuracy bounds improve further when combined with reliability matching.*
